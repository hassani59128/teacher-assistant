# دستیار معلم

نسخه آزمایشی اندروید برای مدیریت مدارس، کلاس‌ها و درس‌ها.

## امکانات فعلی
- ثبت و نمایش مدرسه‌ها
- ثبت کلاس و اتصال آن به مدرسه
- ثبت مستقل درس‌ها
- ذخیره اطلاعات روی گوشی با Room Database

## ساخت APK
با GitHub Actions:
1. فایل‌ها را در مخزن GitHub بارگذاری کنید.
2. به زبانه Actions بروید.
3. گردش‌کار Build Android APK را اجرا کنید یا پس از push شدن کد، اجرای خودکار را ببینید.
4. از بخش Artifacts فایل teacher-assistant-debug-apk را دانلود کنید.
